CHƯƠNG TRÌNH THỰC HÀNH: TẠO MENU NGANG

Cách chạy:
1. Giải nén file ZIP.
2. Mở thư mục tao_menu_ngang bằng VS Code.
3. Mở file index.html.
4. Nếu đã cài Live Server: nhấn chuột phải trong index.html > Open with Live Server.
   Hoặc nhấp đúp index.html để mở trực tiếp bằng trình duyệt.

Kiểm tra:
- Menu Sem 1, Sem 2, Sem 3, Sem 4 nằm ngang.
- Rê chuột vào Sem 1 hoặc Sem 2 để hiện menu con.
- Rê chuột vào mục menu để nền chuyển đỏ.

Hai file index.html và styles.css phải nằm cùng thư mục.
